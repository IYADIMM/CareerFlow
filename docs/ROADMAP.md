# Dependency-aware roadmap

## M0 — Audit and architecture (complete)

Preserve the original visual system; define product, security, data, testing, deployment and feature truth; create a clean local project.

## M1 — Foundation (working local slice)

React/TypeScript shell, routes, local identity disclosure, Career Digital Twin foundation, command center, action completion, ten-stage map, responsive states and deletion. Next: connect Supabase development auth and replace local persistence.

## M2 — Revenue MVP

1. Auth + membership enforcement and private documents.
2. CV upload, extraction boundary and human verification.
3. Vacancy import, transparent deterministic matching and seniority protection.
4. Evidence-safe CV tailoring and version history.
5. Application tracker and interview preparation.
6. Server-side plans, entitlements, usage limits and founder-operated pilot provisioning.

## M3 — Advanced intelligence

Skills plans, recommendation orchestration, recruiter CRM, interview simulations, offer comparison and growth plans after evaluation fixtures and cost controls exist.

## M4 — Commercial platform

Approved vacancy sources, periodic discovery, notifications, verified billing, agency workflows, analytics and i18n/RTL.

## M5 — Hardening

Authorization/E2E/accessibility/load tests, recovery drill, monitoring, legal review, cost budgets and production-readiness sign-off.
